## 更流畅、更明确的时间线操作

- 优化片段在轨道内及轨道间拖动时的更新节奏，减少卡顿感。
- 加强选中片段的视觉反馈，更容易确认当前操作对象。
- 修复时间轴与功能区争夺键盘焦点的问题；选中片段后，空格播放和 Delete 删除能够稳定作用于时间线。
- `LINKED` / `UNLINKED` 现在与真实链接状态一致，导入的视频与音频也可以可靠地取消链接。

## 播放与稳定性修复

- 修复纯音频时间线播放到结尾后仍保持“正在播放”状态的问题。
- 减少音频控制、导出进度和项目状态变化触发的不必要界面更新。
- 加强项目文件替换、缓存清理以及缺失或锁定路径下的容错处理。
- 新增音频播放结束、快捷键路由、链接片段、缓存和项目文件等回归测试。

## 全新的统一图标

- Windows 应用窗口、可执行文件、安装包资源和仓库文档统一使用新的紫蓝色 zClip 图标。
- README 图标改为更醒目的居中展示，并可直接进入最新 Release。
- 同步更新界面演示和仓库社交预览资源。

## English summary

zClip 2.5.1 improves timeline dragging, selected-clip feedback, and keyboard routing; fixes unlinking and audio-only playback completion; reduces unnecessary UI updates; hardens project/cache handling; and refreshes the app, installer, and documentation with one unified zClip icon. This Windows build is explicitly unsigned, so verify it with `SHA256SUMS.txt` before running.
