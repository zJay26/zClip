## 更顺手的界面

- 工具栏新增深色 / 浅色模式切换。
- 界面可在中文与 English 之间切换，两项偏好都会保存在本机。
- 新增项目 FPS、预览画面直接定位、素材重新定位，以及更完整的项目打开和保存流程。

## 更放心地完成一次导出

- 项目与导出先写入临时文件，验证成功后才替换目标；失败或取消不会破坏已有成品。
- 修复转场、画面变换、竖屏尺寸、音频淡化、音调与倍速组合等导出问题。
- 长时间线、音频预览、媒体缓存和后台任务增加资源上限，减少大项目中的卡顿与内存堆积。

## 安全与可验证性

- Electron Renderer 使用 sandbox、context isolation、严格 CSP 和能力授权路径。
- 生产界面改由受限的 `zclip-app://` 协议加载，并启用 ASAR 完整性与 hardened fuses。
- FFmpeg/FFprobe 固定为 8.1.2 并逐文件校验 SHA-256；Release 同时提供 SBOM、第三方声明、来源信息和校验和。

## English summary

zClip 2.5.0 adds dark/light themes, Chinese/English switching, project FPS, safer project and export writes, more reliable transitions and audio processing, bounded media resources, hardened Electron boundaries, and verifiable release provenance. This Windows build is explicitly unsigned; verify it with `SHA256SUMS.txt` before running.
