zClip 2.7.0 改进日常剪辑、项目保存和导出稳定性，继续兼容 schema v1 的 `.zclip` 项目。

## 编辑更顺手

- 新增“删除并关闭空隙”（`Shift+Delete`）和时间线“编辑 → 消除全部空隙”。所有轨道一起移动，只移除没有任何素材覆盖的时间段；背景音乐覆盖的时间会保留。这些操作均可撤销。
- 复制粘贴保留所选片段之间的转场、音频淡化、音画链接及轨道，并重新生成效果 ID。
- 新增全选（`Ctrl+A`）、取消选择（`Esc`）、前后剪辑点（`↑` / `↓`）、时间线首尾（`Home` / `End`）、导入（`Ctrl+I`）和导出（`Ctrl+E`）。
- 按 `F1` 或点击顶部键盘图标查看快捷键帮助，支持中文、English、深色和浅色主题。

## 保存与导出更可靠

- 删除全部素材后也能保存与恢复空项目，同时停止播放并归位播放头。
- 连续保存只触发一次请求；保存对话框打开期间的编辑会纳入保存。旧保存完成后不会把路径或已保存状态写入另一个项目。
- 保存期间的新改动继续标为未保存，“保存并退出”会检查这些改动。
- 超过 25 MB 的项目会在替换文件前拒绝写入，避免生成无法重新打开的项目，并保留已有项目和恢复文件。
- 导出对话框和 IPC 异常会恢复可操作状态；取消导出会等待后台清理结束，忽略取消后的迟到事件，并防止重复启动。

## 界面与维护

- 修复弹窗更新时输入焦点跳回关闭按钮的问题，并保留输入框的原生撤销等快捷键。
- 修复缩放为 1 时“适配”不刷新的问题，支持长时间线完整适配和触控板水平滚动。
- 优化批量删除链接片段与空隙时间映射，更新存在审计问题的兼容依赖。
- 补充自动回归与打包界面检查，覆盖新编辑操作、保存竞争、导出取消、焦点和文件保护。

## 下载与核验

支持 Windows 10/11 x64。安装包为 `zClip.Setup.2.7.0.exe`，签名状态以随附的 `SIGNING_STATUS.txt` 为准；未配置商业证书时为明确标注的 `UNSIGNED`，Windows 可能显示“未知发布者”。请从本 Release 下载并核对 `SHA256SUMS.txt`。同时附带 CycloneDX SBOM、FFmpeg 来源和第三方声明。

## English summary

zClip 2.7.0 adds synchronized gap closing, complete effect-aware clipboard operations, selection/navigation shortcuts and bilingual keyboard help. It improves empty-project persistence, save concurrency and document isolation, export cancellation/error handling, dialog focus and long-timeline fitting. Existing schema-v1 projects remain compatible. Verify the Windows installer against the included checksums and signing-status file.
