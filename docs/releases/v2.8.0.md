zClip 2.8.0 新增可选的软件更新功能，兼容现有 schema v1 的 `.zclip` 项目。

## 由用户决定何时更新

- 工具栏新增“软件更新”入口，支持中文、English、深色和浅色主题。
- 默认每 6 小时检查 GitHub 上的正式新版本；首次运行或检查已到期时，在启动约 10 秒后检查。仅在应用运行时工作，可关闭，仍可随时手动检查。
- 发现更新只显示可忽略的提示，可以查看版本说明、下载或稍后再说；不会自动下载、强制升级或在普通退出时安装。
- 下载目录可通过原生文件夹选择器配置并持久保存。安装包存入独立子文件夹，不覆盖已有同名文件；提供进度、取消和失败重试。
- 下载完成后及安装前分别核对官方 Release 元数据中的 SHA-256 和文件大小，失败时禁止安装。中断或失败的临时下载会清理。
- 点击“退出并安装”才会启动普通 Windows 安装向导，先处理未保存项目。导出或媒体处理期间暂不可安装；也可继续使用当前版本，稍后运行保留的安装包。
- 更新请求不上传媒体和项目，剪辑与导出继续支持离线使用。

## 首次升级与下载

v2.7.0 及更早版本尚无更新功能，请先手动安装本次 Release。支持 Windows 10/11 x64，安装包为 `zClip.Setup.2.8.0.exe`。签名状态见 `SIGNING_STATUS.txt`；未配置商业证书时明确标记为 `UNSIGNED`。Release 同时提供 `SHA256SUMS.txt`、CycloneDX SBOM、FFmpeg 来源和第三方声明。

## English summary

zClip 2.8.0 adds optional software updates: six-hour checks while running, a persistent on/off setting, manual checks, release notes, configurable download directory, progress, cancellation and retry. Discovery never downloads or installs automatically. Installers are verified against the official release SHA-256 and size after download and again before launch. Quit and install uses the existing unsaved-project confirmation. Older versions need one manual upgrade to gain this feature; editing and exporting remain available offline.
