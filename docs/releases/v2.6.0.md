## 转场播放与交互重做

- 修复普通剪辑点偶发黑帧，以及进入、越过和离开转场时的卡顿、跳变与错误画面。
- 叠化等转场在衔接点保持连续合成，不再被后一段视频突然覆盖。
- 转场拖放以效果方框是否接触剪辑点为准，释放范围更宽、更直观。
- 选中转场时取消片段选中，并在转场面板中直接调整时长与对齐方式。
- 用新转场替换已有转场时保留当前参数；无效轨道、空隙和不相邻片段会被可靠拒绝。

## 音频与时间线稳定性

- 修复画面与音频取消链接并删除音频后，视频仍播放原始内嵌音频的问题。
- 加强移动、裁剪、倍速、删除及项目恢复时的转场约束，避免产生无效状态。
- 增加普通剪辑点、转场边界、取消链接音频和拖放几何等自动回归测试。

## 更快、更可靠的导出

- 高倍速视频在缩放和合成前提前抽帧；简单单片段与连续片段使用轻量快路径。
- 按实际素材区间进行输入级定位，避免无谓解码完整源文件。
- 擦除转场的逐像素计算只在转场区间运行，显著降低长片段开销。
- GIF 改为有界两阶段调色板导出，WebP 和 GIF 的长素材导出不再依赖高内存的共享帧队列。
- VP9 启用行级与分块并行；H.264 自动实测 NVENC、QSV、AMF，并在硬件失败时回退 `libx264`。
- 11 种支持格式均加入真实 FFmpeg 导出验证。

## English summary

zClip 2.6.0 reworks transition playback and editing, fixes detached-audio playback, and substantially improves export speed and reliability. It adds early frame decimation, bounded input seeking, simple timeline fast paths, two-pass GIF palettes, VP9 parallelism, and runtime-tested H.264 hardware acceleration with automatic software fallback. This Windows build is explicitly unsigned, so verify it with `SHA256SUMS.txt` before running.
